# CommerceOS Frontend

**React 19 + Vite 8 + React Router + Tailwind CSS 4**

## Run

From project root:

```bash
npm run dev:frontend
```

Or from this folder:

```bash
npm run dev
```

Open http://localhost:3000 — API requests proxy to http://localhost:5000/api

## Stack

- React.js (not Next.js)
- Vite
- Tailwind CSS + custom CSS variables
- Axios → Node/Express backend
- MongoDB (via backend)
